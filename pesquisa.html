Assistente de Balanceamento com I.A. (League of Legends)

Tipo: Ciência de Dados & Balanceamento de Sistemas (Projeto de Conclusão do MBA)

Uma ferramenta analítica desenvolvida em Python para avaliar o meta competitivo de League of Legends. O sistema processa taxas de vitória, taxas de escolha e sinergias para prever mudanças no meta e identificar mecânicas tóxicas. Aplicando ciência de dados ao game design, a ferramenta oferece insights práticos para equilibrar ecossistemas competitivos.

Competências: Python, Análise de Dados, Balanceamento de Meta, System Design.

Plugin Other Half: Geração de Normal Maps

Tipo: Art Técnica & Desenvolvimento de Ferramentas (Pesquisa de Mestrado)

Artigo acadêmico aceito e apresentado no palco do Eurographics 2026. O projeto apresenta um plugin customizado para Unity capaz de extrair e gerar normal maps dinamicamente a partir dos valores de escala de cinza de pixel art 2D. A ferramenta une a estética tradicional 2D a sistemas complexos de iluminação 3D.

Competências: Technical Art, Desenvolvimento de Ferramentas, Unity, Pesquisa Acadêmica.
