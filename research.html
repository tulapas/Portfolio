Data Science Applied to Competitive Game Balancing: A Case Study in League of Legends

Type: Data Science & System Balancing (MBA Capstone Project)

Development of an automated, predictive methodology to identify and diagnose balance issues within the competitive ecosystem of Games as a Service. Utilizing the Riot API, complex tabular data was compiled from the Korean server (KR), capturing high-tier matches across Master, Grandmaster, and Challenger ranks to assess optimal meta conditions.

By training a predictive Random Forest machine learning model, the system achieved a high classification accuracy of 0.87 when predicting match outcomes. The data analysis revealed critical design insights: specific itemization structures and customization options (such as Ionian Boots of Lucidity and Plated Steelcaps) wield an overwhelming importance on match success, outclassing individual champion variables and serving as an accurate tool for live-game designers.

Key Skills: Python, Pandas, Machine Learning (Random Forest), Data Analytics, Meta Balancing, System Design.

High-Performance Automated Normal Mapping for 2D Games (Unity Plugin)

Type: Technical Art, Visual Computing & Tool Development (Master's Research)

Peer-reviewed academic publication accepted and presented live on stage at Eurographics 2026. Formed by team Hó, Hô & Xo at the University of Aveiro, the project builds a functional software solution to compute and extract automated normal maps in 1 second based on grayscale values from 2D pixel art.

Rigorous validation with industry artists confirmed a monumental 1,140x productivity leap compared to traditional workflows, reclaiming 19 minutes of labor per sprite down to instant generation. In blind studies, the algorithmic tool achieved unanimous aesthetic preference for realistic lighting depth and seamless gradients, grading a 9.6/10 usability metric and a 100% recommendation score for professional development pipelines.

Key Skills: Unity Plugin Development, C#, Visual Computing, Dynamic Lighting, Technical Art, Academic Research.
